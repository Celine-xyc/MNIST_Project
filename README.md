# MNIST手写数字识别项目
##1.模型结构
我使用PyTorch构建神经网络，先在mnist.py里面构架模型从28*28的二维平面转化为784个像素点即一维平面，最后输出0~9十个数字
项目直接使用群里发的四个数据文件：测试集以及训练集
##2训练过程
在train.py里面进行训练，训练过程步骤很多要import torch，读取训练集和测试集的内容对模型进行3轮训练 性能评估最终输出测试集的准确率并保存到model.pth 运行环境：Python PyTorch CPU环境
mnist.py   data_loader.py   train.py这三个一起跑最终成功搞好了这个项目
